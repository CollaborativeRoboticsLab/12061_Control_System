# Week 4

**`Control_System_Lab2.m`** — signals, scaling, time response

Run it **one section at a time with Ctrl+Enter**. Never Run All: several
sections need you to be holding the rod when they start.

Before the first section, run `setupPath` once from `MATLAB_Code/`. The script
locates its own data folder through the MATLAB search path, so `setupPath` is
not optional.

Captures land in `week4/data/`, named with your `cfg.GROUP_ID`. Set that in
Section 0 or you will overwrite another group's files.

See `../README.md` for the week table and the folder convention.
